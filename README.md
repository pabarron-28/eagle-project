# St. Thomas More Nativity Scene Eagle Project
## Project Overview
St. Thomas More Catholic Church wanted a new large-scale Nativity scene to be displayed outside during every Christmas season. Their previous Nativity shelter was one piece, getting old, and was exceptionally hard to transport. My new Nativity shelter was able to be disassembled into 7 separate pieces, allowing for easy transport.
## Tool Used
-CAD Software: after physically designing the shelter, I had help from my uncle who put the project blueprints into a CAD software
## Results
The church was elated with the project, and they to this day display my Nativity shelter every Christmas season.
